# Codebase-Explorer

## Введение

Codebase-Explorer - это веб-приложение для анализа и исследования кодовых баз. Проект включает FastAPI бэкенд для обработки репозиториев, парсинга Python файлов и генерации структур папок.

## Архитектура

Проект состоит из трех основных компонентов:
- **Бэкенд**: FastAPI приложение на Python
- **Фронтенд**: Веб-интерфейс (планируется)
- **LLM**: Сервис для генерации описаний с использованием Hugging Face TGI

## Функциональность

### Реализованная функциональность
- Загрузка и анализ репозиториев
- Парсинг Python файлов с извлечением классов, функций и докстрингов
- Рекурсивная обработка структур папок
- Интеграция README файлов на уровне папок
- REST API эндпоинты для получения структур

### Добавления и обновления в чате
- **Парсинг Python файлов**: Реализован AST-парсинг для извлечения классов, функций, методов и их документации
- **Рекурсивные структуры папок**: Добавлена поддержка глубокого обхода директорий с правильной вложенностью
- **Интеграция README**: README файлы теперь читаются и включаются в описания папок
- **Docker контейнеризация**: Созданы Dockerfile, docker-compose.yml для развертывания полного стека (бэкенд, фронтенд, LLM)
- **Схемы данных**: Обновлены Pydantic модели для поддержки рекурсивных структур и README полей
- **Тестирование**: Добавлены тесты для API эндпоинтов

## Установка и запуск

### Локальная разработка
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Docker развертывание
```bash
docker-compose up --build
```

## Структура проекта

```
├── app/                    # FastAPI приложение
│   ├── api/               # API эндпоинты
│   ├── core/              # Конфигурация и исключения
│   ├── schemas/           # Pydantic модели
│   └── services/          # Бизнес-логика
├── storage/               # Хранение репозиториев
├── tests/                 # Тесты
├── frontend/              # Веб-интерфейс (планируется)
├── llm/                   # Конфигурации LLM (планируется)
├── Dockerfile             # Контейнер бэкенда
├── docker-compose.yml     # Оркестрация сервисов
└── requirements.txt       # Python зависимости
```

## API

- `POST /api/repos/upload` - Загрузка репозитория
- `GET /api/repos/{repo_id}/structure` - Получение структуры репозитория

## Разработка

Проект использует:
- FastAPI для веб-фреймворка
- Pydantic для валидации данных
- Python AST для парсинга кода
- Docker для контейнеризации
- pytest для тестирования
